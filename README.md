# Security Journey - AppSec & Pentesting Roadmap (12 Weeks)

Nhật ký học tập và xây dựng công cụ bảo mật ứng dụng bằng Python.

## Mục tiêu 12 tuần
- [ ] Xây dựng 3 công cụ bảo mật bằng Python (Directory Brute-forcer, Port Scanner, Security Header Checker).
- [ ] Hoàn thành các bài lab SQLi, Access Control, Business Logic (PortSwigger Apprentice).
- [ ] Giải 20 bài picoCTF (tối thiểu 5 bài giải tự động bằng script Python).
- [ ] Viết 3 bài Write-up hoàn chỉnh.

## Nhật ký theo tuần
- **Tuần 0:** Thiết lập môi trường & Kiểm tra đầu vào Python.
- **Tuần 1:** Nền tảng mạng (IP, Port, DNS, TCP) & Thư viện `requests`.
